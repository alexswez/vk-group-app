# Сервер общего хранилища (этап 5)

Зачем он нужен: VK Storage хранит переменные **для каждого пользователя отдельно**, поэтому
расписание и задания, добавленные одним студентом, не увидели бы остальные. Общие данные
должны лежать в одном месте — на сервере.

## Запуск

```powershell
cd server
npm install
npm start
```

Сервер поднимется на http://localhost:3000. Проверка: http://localhost:3000/health

## API

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/group` | Все общие данные: предметы, пары, задания, название группы |
| POST | `/api/tasks` | Добавить задание |
| PUT | `/api/tasks/:id` | Изменить задание целиком |
| PATCH | `/api/tasks/:id` | Изменить статус задания |
| DELETE | `/api/tasks/:id` | Удалить задание |
| POST | `/api/lessons` | Добавить пару |
| PUT | `/api/lessons/:id` | Изменить пару |
| DELETE | `/api/lessons/:id` | Удалить пару |
| PUT | `/api/settings` | Сохранить название группы |
| POST | `/api/reset` | Сбросить базу к тестовым данным |

Любой изменяющий запрос возвращает **полный** набор данных группы — так фронтенду проще:
он просто заменяет своё состояние целиком.

## Где лежат данные

Файл `server/data/app.db` (SQLite). Он создаётся автоматически при первом запуске
и наполняется тестовыми данными. Папка `data/` не попадает в git.

## Что сказать на защите

- **Почему SQLite, а не PostgreSQL.** Это тот же SQL и те же таблицы; выбран потому, что не
  требует установки сервера БД. Переход на PostgreSQL = замена `node:sqlite` на пакет `pg`
  и правка примерно 10 строк подключения. Схема таблиц остаётся прежней.
- **Почему `node:sqlite`, а не `better-sqlite3`.** Встроен в Node.js 22.5+, не требует
  компиляции нативных модулей — проект собирается «из коробки» на любой машине.
- **Безопасность.** Сейчас сервер доверяет полю `authorName`, которое присылает клиент.
  В боевом варианте нужно проверять подпись параметров запуска VK (`sign`) и брать имя
  пользователя из проверенных данных — иначе автор задания подделывается.
- **CORS.** Открыт для всех источников, потому что фронтенд и сервер живут на разных портах
  при разработке. Перед публикацией список источников нужно ограничить.
