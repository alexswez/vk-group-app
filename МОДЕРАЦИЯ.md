# Доступ для одногруппников: два пути

Пока приложение **не прошло модерацию**, ВКонтакте открывает его только администраторам
приложения. Это правило платформы: так ВКонтакте защищает пользователей от недоделанных
приложений. Именно поэтому одногруппники видят сообщение, что приложение доступно только
администраторам.

Администраторов у приложения мало, и каждый требует подтверждения от добавляемого человека —
для группы, которая собирается раз в полгода, это не работает.

Ниже два пути: быстрый (сегодня) и правильный (один раз настроить).

---

## Путь 1. Быстро: ссылка на хостинг (без ВКонтакте)

Сборка приложения лежит на хостинге ВКонтакте и **открывается в обычном браузере** — без
проверки прав, потому что это просто веб-страница. Приложение умеет работать без ВКонтакте:
личные настройки в этом случае хранятся в браузере, а общие данные — по-прежнему в облаке.

**Как отправить:** скинь в беседу группы ссылку вида

```
https://prod-app54822849-<код>.pages-ac.vk-apps.ru/index.html
```

Актуальную ссылку печатает команда `npm run deploy` (строки «URLs changed for production»).

**Важно понимать:**
- ссылка **меняется при каждой публикации**, поэтому подходит как временное решение;
- имя и аватар в «Настройках» и кнопка «Поделиться» в этом режиме не работают (для них нужен
  ВКонтакте), но расписание, задания, материалы и их редактирование работают полностью;
- одногруппники могут открыть ссылку и внутри ВКонтакте (встроенный браузер) — ограничение
  платформы действует только на карточку приложения, а не на прямую ссылку на хостинг.

## Путь 2. Правильно: пройти модерацию (один раз)

После модерации приложение открывается у **любого** пользователя по ссылке
`https://vk.com/app54822849` — никаких подтверждений и списков администраторов.

### Что нужно подготовить

| Что | Где взять |
|---|---|
| Название | «Расписание группы ИСПСВ-301» |
| Иконка 512×512 | [public/app-icon-512.png](../public/app-icon-512.png) — уже нарисована |
| Описание | см. текст ниже |
| Скриншоты (2–4 штуки) | сделать на телефоне: расписание, задания, материалы |
| Категория | «Образование» |
| Политика конфиденциальности | [public/privacy.html](../public/privacy.html) — уже написана, публикуется вместе с приложением: `<адрес хостинга>/privacy.html` |

### Текст описания (можно скопировать)

> Приложение для учебной группы ИСПСВ-301: расписание занятий (сессия и дистанционный период),
> список предметов и заданий с напоминанием о сроках, общее хранилище учебных материалов
> с возможностью прикрепить файл. Данные общие для всей группы: изменения видны всем сразу.
> Расписание можно отправить в беседу группы одним нажатием.

### Порядок действий в кабинете

1. Открыть https://dev.vk.com → «Мои приложения» → приложение **54822849**.
2. Заполнить карточку: название, описание, иконку, скриншоты, категорию, платформы
   (iOS, Android, Web, Mobile Web).
3. В настройках указать ссылку на политику конфиденциальности.
4. Нажать **«Отправить на модерацию»**.
5. Дождаться решения (обычно несколько рабочих дней). Если вернут с замечаниями — исправить
   и отправить снова.

После одобрения ссылка `https://vk.com/app54822849` работает у всех, и приложение можно
закрепить в беседе группы.

> Замечание: приложение не обязано попадать в каталог ВКонтакте — для группы достаточно,
> чтобы ссылка открывалась. Если публичность не нужна, не указывай приложение в подборках
> и не рекламируй его: пользоваться им будут только те, кому ты дал ссылку.
